Obtaining a Statue Core <Asset location="statues:statue_core" title="Statue Core" width={64}/>
=======================
Statue Core's are dropped by the Statue Bat. 
<Asset location="statues:statue-bat" title="Statue Bat" width={256}/>
The Statue bat just like the vanilla one can be found in dark areas but beware! It hurts you back if you try to kill it.
